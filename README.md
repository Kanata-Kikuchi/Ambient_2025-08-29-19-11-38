# Ambient_2025-08-29-19-11-38

SuperCollider を用いたライブコーディング演奏用の素材です。  
演奏時にはコードをリアルタイムで書き換えるため、本リポジトリには初期状態のコードを保存しています。


---


## 構成ファイル

- 音源コード：`src.scd`

- 演奏コード：`perf.scd`


---


## 技術構成

使用言語 / 環境：
- SuperCollider


---


## 使い方 / 起動方法

1. SuperColliderを起動します
2. `Ctrl + B` でサーバーを起動します
3. `src.scd` 内の音源を実行し、サーバーに登録します
4. `perf.scd` をそれぞれ実行し、演奏を行います
